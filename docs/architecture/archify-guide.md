# Archify Integration & Usage Guide

Quick reference guide for using **Archify** interactive system maps and architecture diffs in ArchitectAI.

---

## 1. Overview

Archify (v1.7.0+) provides interactive diagram rendering and visual architecture diffing (*Before vs Delta vs After*) for software engineering packages created by ArchitectAI.

---

## 2. Usage Workflows

### A. Generated Engineering Packages (`04-diagrams/`)
Every project generated by ArchitectAI includes Archify artifacts in its export ZIP package:
- **`04-diagrams/architecture-interactive.html`**: Self-contained interactive HTML map. Open in any web browser for pan/zoom, layer filtering, component search, and dependency highlighting.
- **`04-diagrams/archify-spec.json`**: Structural JSON Intermediate Representation (IR) specification.

### B. Generating System Maps for Local Codebases
To generate or refresh the interactive system map for ArchitectAI:
```bash
npx tsx scripts/generate-system-map.ts
```
**Outputs:**
- `docs/architecture/system-map.html` (interactive HTML view)
- `docs/architecture/system-map.json` (JSON IR specification)

### C. Programmatic API & Architecture Diffing

#### Generating IR and HTML
```typescript
import { generateArchifyIR, compileArchifyHtml } from './src/diagrams/archify.js';

const ir = generateArchifyIR(architectureDoc, 'My System Map');
const html = compileArchifyHtml(ir);
```

#### Comparing Architecture Snapshots (*Before vs Delta vs After*)
```typescript
import { compareArchitectureDocuments } from './src/review/diff-service.js';

const diffPackage = compareArchitectureDocuments(beforeDoc, afterDoc, 'PR Architecture Audit');

console.log(diffPackage.summaryText);
// diffPackage.htmlReport contains the interactive Before / Delta / After HTML report
```

### D. AI Agent Skill Usage
AI coding agents (Antigravity, Cursor, Claude Code, etc.) can invoke the installed Archify skill:
- **Guide File**: `docs/skills/archify-skill.md`
- **Global Location**: `~/.agents/skills/archify`
- **Sample Prompts**:
  - *"Generate an interactive system map for this refactored component."*
  - *"Run an Architecture Diff between `main` and this feature branch."*
